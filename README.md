# 👁 بصير — عيون المالك | Bassir Owner Eyes

منصة رؤية بصرية لإدارة المشاريع الإنشائية تربط **المالك** بـ **المكتب الاستشاري** و**المقاولين**، بحيث يعرف المالك حالة مشروعه **من النظر** — دون حاجة لوقت أو خبرة هندسية.

> الفكرة: المخططات والنموذج ثلاثي الأبعاد تظهر **داكنة** للأعمال غير المنتهية وتتحول إلى **ساطعة متوهجة** كلما اكتملت البنود واعتُمدت مستخلصاتها.

---

## التشغيل

يلزم Node.js 22+ (لقاعدة بيانات SQLite المدمجة):

```bash
npm install            # يثبت @anthropic-ai/sdk لتحليل الصور (اختياري)
node server/server.js  # ثم افتح http://localhost:3000
```

عند الإقلاع تُشفَّر كلمات المرور تلقائياً وتُنشأ قاعدة بيانات SQLite في `data/bassir.db`.

- `npm run seed` — إعادة ضبط بيانات الديمو
- `npm run build:demo` — توليد ديمو تفاعلي بملف واحد `demo/bassir-demo.html` يعمل بلا خادم (يفتح مباشرة في المتصفح)

## المستويات والصفحات

### 1) الأدمن
مطلع على كل شيء: جميع الصفحات + إدارة المستخدمين + حذف السجلات (كلمات المرور مشفرة scrypt ولا تظهر لأحد).

### 2) المالك
مالك المشروع **مقيد بمشروعه المسند إليه** (اطلاع فقط، لا يضيف ولا يعدل):
- **👁 عين المالك**: حالة المشروع بنظرة واحدة — ثلاثة أحكام فورية ملوّنة: **الوقت** (متأخر/متقدم/حسب الجدول مع عدد الأيام والمدة المنقضية)، **الإنجاز** (الفعلي مقابل المخطط والانحراف)، **التكلفة** (التقديرية مقابل الفعلية ونسبة التجاوز/الوفر) + شريط إنجاز الأدوار داكن/ساطع، والضغط على أي دور يفتحه في رؤية المشروع. تدعم تعدد المشاريع للمالك الواحد.
- **لوحة القيادة**: الجدول الزمني الفعلي والتقديري (منحنى S)، التكلفة الفعلية والتقديرية، مراحل المشروع، تنبيهات ذكية.
- **رؤية المشروع**:
  - مخططات 2D لكل دور مربوطة بجدول الكميات — خطوط المخطط **باهتة** للأعمال غير المنفذة وتتحول **ساطعة** عند التنفيذ واعتماد الاستشاري، مع تصفية حسب التخصص (معماري، إنشائي، كهرباء، HVAC، صحي، حريق، فرش...) وشريط نِسَب التخصصات لكل دور وقائمة المخططات المرفوعة المرتبطة بالدور.
  - **🏙️ واجهات المبنى (High-Rise)**: مخطط واجهة يعرض نسبة إنهاء كل دور بنوافذ تضيء مع التقدم — والضغط على أي دور يفتح النظام مسقطه **تلقائياً** مع نسب المعماري والإنشائي والكهروميكانيكا وبقية التخصصات.
  - نموذج BIM أيزومتري مربوط بجدول الكميات — الأدوار المكتملة تتوهج، والضغط على أي دور يعرض تفصيل تخصصاته.
- **🎥 كاميرات الموقع**: بث مباشر من كاميرات المشروع مع حالة كل كاميرا، ويحلل الذكاء الاصطناعي اللقطات كل 30 دقيقة. الاستشاري يربط كاميرات جديدة برابط RTSP.
- **المقاولون والأداء**: عدد المقاولين، نسبة إنجاز كل مقاول، المبالغ المستلمة، التخصص، هل هو متأخر؟ هل استلم أكثر من مستحقه؟ (مقارنة بالقيمة المكتسبة Earned Value).
- **ذكاء بصير الاصطناعي**: نسبة إنجاز مرصودة بصرياً من الصور والكاميرات مقابل المُبلَّغ، مع **جدول مقارنة الرصد البصري بنسب الاستشاري** (فرق أكثر من 5% = تحقق ميداني)، ورؤى ونصائح وتنبيهات (فروقات إنجاز، تأخر وتيرة، تنبيهات سلامة ومالية).
- **التقارير والإرسال**: تقارير يومية وأسبوعية وشهرية + إرسال للمالك عبر واتساب أو الإيميل مع سجل إرسال.

### 3) ممثل المالك
يطلع على كامل ملفات ومعلومات جميع المشاريع + **إضافة مشروع وتعيين استشاري** وإنشاء اسم مستخدم وكلمة مرور له + **المستخدمون والصلاحيات** + **📜 سجل النظام**.

### 4) الاستشاري (المكتب الفني)
- **الاعتمادات**: استقبال طلبات المقاولين والبت فيها بتوقيع إلكتروني وملاحظات — المخططات التنفيذية، الجداول الزمنية، المواد والداتا شيت، طلبات استلام الأعمال (قبول / قبول بملاحظات / رفض)، أوامر التغيير، **المستخلصات** (اعتمادها يحدّث نسب بنود الكميات فتتحول المخططات من داكنة إلى ساطعة ويُحدَّث رصيد المقاول).
- **خدمات المكتب الفني** (موديول متكامل بمؤشرات ولوحة تبويبات):
  1. **الاستفسارات الفنية RFI** — استقبال استفسارات المقاولين وحسم تعارضات المخططات بالرد الموقع.
  2. **تقارير عدم المطابقة NCR** — رصد الأعمال المخالفة بدرجات خطورة، ومتابعة الإجراء التصحيحي حتى الإغلاق.
  3. **التعليمات الموقعية Site Instructions** — إصدار تعليمات ملزمة ومتابعة تنفيذها.
  4. **أساليب التنفيذ وخطط الفحص MS/ITP** — اعتماد Method Statements وInspection & Test Plans.
  5. **اختبارات المواد** — توثيق نتائج الاختبارات المعملية والحقلية (كسر مكعبات، ضغط، شد...) ناجح/راسب.
  6. **محاضر الاجتماعات MoM** — اجتماعات التنسيق الأسبوعية وحضورها وقراراتها.
  7. **قوائم الملاحظات Snag List** — ملاحظات الاستلام الابتدائي بالمواقع ومتابعة إغلاقها.
  8. **السلامة HSE** — مخالفات وحوادث وملاحظات وقائية بدرجات خطورة.
  9. **المطالبات وتمديد المدة Claims/EOT** — دراسة المطالبات المالية وطلبات التمديد والبت فيها.
  10. **الهندسة القيمية VE** — دراسة مقترحات خفض التكلفة والوفر المتوقع.
  11. **التسليم والإغلاق** — مخططات كما نُفذ As-Built، كتيبات O&M، الضمانات، فترة الضمان DLP.
  12. **سجل المراسلات** — الخطابات الصادرة والواردة الرسمية.
- **جداول الكميات**: عرض وتحديث نسب الإنجاز لكل بند (ينعكس مباشرة على المخططات).
- **إدارة المقاولين**: إضافة مقاول بجدول كمياته وأسعاره وتواريخ عقده وتخصصه + إنشاء حساب دخول له.
- **المخططات والنماذج**: رفع نموذج BIM وربطه بجدول الكميات + **سجل مخططات المشروع** (مساقط وواجهات لكل دور وتخصص، كل مخطط مربوط بجدول كمياته فيظهر للمالك داكناً/ساطعاً حسب التنفيذ).
- **🖊 عارض المستندات مع الترميز (Markup)**: فتح أي مخطط أو **ملف PDF فعلياً داخل النظام** (متعدد الصفحات) والكتابة عليه — ريدلاين، تظليل، سحابة مراجعة، مستطيل، سهم، نص، دبابيس ملاحظات مرقمة، وأختام — مع حفظ الترميز على نفس المستند ثم **الاعتماد أو الإرجاع للمقاول من داخل العارض مباشرة**، وسجل الحالات والنسخ ظاهر في العارض — والمقاول يفتح نفس النسخة، **يرد على كل ملاحظة**، ويعيد التقديم فتؤرشف النسخة السابقة تلقائياً (تفاصيل في قسم وحدات إدارة الوثائق أدناه).
- **إعداد التقارير**: يومية وأسبوعية وشهرية بالصور والملفات الداعمة (إنجازات، معوقات، نسب مقابل المخطط).
- **ربط كاميرات الموقع** الجديدة برابط البث.

### 5) المقاول
- الاطلاع على عقده: القيمة، تاريخا البدء والانتهاء، نسبة إنجازه، المبالغ المستلمة.
- رفع طلباته للاستشاري ومتابعة حالتها: مخططات، مواد، جداول زمنية، طلبات استلام، أوامر تغيير، مستخلصات (مع ربط بنود الكميات ونِسَبها)، استفسارات RFI، أساليب تنفيذ وITP، مطالبات وEOT.
- **صندوق وارد المكتب الفني**: ما يوجَّه إليه من تقارير عدم مطابقة وتعليمات موقعية وملاحظات تسليم وملاحظات سلامة ونتائج اختبارات مواده.

## التكويد والأرشفة

- **تكويد تلقائي لكل مستند**: أي ملف أو اعتماد أو طلب يُنشأ في النظام يأخذ فوراً كوداً معيارياً فريداً بصيغة `BSR-المشروع-النوع-السنة-تسلسل` (مثل `BSR-P1-SD-2026-0007` لمخطط تنفيذي، `BSR-P1-IPC-2026-0003` لمستخلص، `BSR-P1-FIL-2026-0012` لملف مرفوع) — 24 نوع مستند مرمّز.
- **📚 أرشيف المستندات المركزي**: صفحة موحدة لكل مستندات المشروع (مخططات، اعتمادات، مستخلصات، RFI، NCR، تقارير، محاضر، ملفات...) — بحث فوري بالكود أو المرجع أو العنوان أو الجهة، وفلاتر بالنوع والحالة والسنة، وفتح أي مستند بتفاصيله وقراره وتوقيعه ومرفقاته وترميزه من الأرشيف مباشرة. المقاول يرى **أرشيف مستنداته فقط**، والمالك أرشيف مشروعه.

## وحدات إدارة الوثائق والمراجعة (التحسينات الـ11)

- **📄 ترميز PDF داخل النظام (Markup & Review)**: الاستشاري يفتح ملف الـPDF **مباشرة داخل بصير** (عارض PDF.js مدمج، متعدد الصفحات) ويضيف عليه: ريدلاين ✏️، تظليل 🖍، سحابة مراجعة ☁️، مستطيلات وأسهم، نصوص، ملاحظات مرقمة 📍، وأختاماً 🔖 (اعتُمد/بملاحظات/مرفوض/أعد التقديم). الحفظ يتم **على نفس المستند** بلا ملفات مكررة.
- **🔄 دورة مراجعة متصلة على نسخة واحدة**: بعد إرجاع المستند، يفتح المقاول **نفس النسخة**، يرد على كل ملاحظة نصياً (يُسجل الرد باسمه وتاريخه تحت الملاحظة)، ثم يعيد التقديم — فتُؤرشف النسخة السابقة (الملف + الترميز + القرار + التوقيع) تلقائياً في `revisions` داخل المستند نفسه، ويمكن استعراض أي نسخة سابقة من العارض. سجل تدقيق كامل للتعليقات والردود والنسخ في مستند واحد.
- **📋 تتبع التقديمات**: لكل تقديم — رقم الملف (الكود)، الحالة الحالية، تاريخ التقديم، تاريخ بدء المراجعة، تاريخ انتهائها، **مدة المراجعة بالأيام** (تحسب آلياً)، وسجل كامل لكل تغييرات الحالة (Timeline) مع متوسط مدة المراجعة على مستوى المشروع.
- **📮 إدارة RFI وRFP**: إرسال الاستفسارات وطلبات العروض إلى الاستشاري **أو المالك**، تتبع الردود الموقعة وسجلها، و**مدد الاستجابة** لكل طلب مع متوسطها.
- **🔁 أوامر التغيير**: دورة اعتماد مرئية (مُقدَّم ← مراجعة الاستشاري ← القرار) مع تتبع **أثر التكلفة** (وقياسه من الميزانية) و**أثر الجدول الزمني** (أيام التمديد) للمعتمد والمعلق.
- **🗃️ قاعدة بيانات المقاولين**: اسم الشركة، العنوان، مسؤول التواصل، الهاتف، البريد، السجل التجاري، الرخص، الشهادات والتصنيفات، والوثائق القانونية — قابلة للتحديث من الاستشاري/الأدمن.
- **🗄️ خادم الملفات المركزي**: تخزين آمن مُكوَّد، بحث واسترجاع سهل، **سجل نسخ لكل ملف** (رفع نسخة جديدة يؤرشف السابقة بلا سجل مكرر)، فئات منظمة، ونسخ احتياطي كامل لقاعدة البيانات بزر واحد (أدمن) عبر `/api/actions/backup`.
- **📁 وثائق المشروع**: مستودع لكل مشروع بفئات: العقود، جداول الكميات BOQ، التصاميم الأولية، مخططات IFC، المواصفات، متطلبات المالك، وثائق فنية، تقارير — والمالك يطلع على وثائق مشروعه.
- **🧊 إدارة BIM**: رفع النماذج **سحابياً** (ربط رابط Autodesk/Trimble...) أو **من الجهاز** (ملفات كبيرة حتى 500MB)، وسجل نماذج بإصداراتها وربطها بجدول الكميات. **قوالب وثائق BIM** جاهزة تُحرَّر وتُكوَّد: BEP، MIDP، تقرير اكتشاف التعارضات، وتقرير الإغلاق Close-Out.
- **🎥 ربط الكاميرات بنموذج BIM**: كل كاميرا تُربط بدور وتخصص في النموذج، وكل لقطة تصل تُحلل بالذكاء الاصطناعي وتُقارن **آلياً** نسبتها المرصودة بنسبة النموذج/جدول الكميات — تحقق أسهل من التقدم الفعلي.
- **🗂️ لوحة المشاريع**: عرض كل المشاريع ببطاقات (الإنجاز، المقاولون، المعلقات، الملفات، الميزانية) واختيار المشروع للعمل عليه — كل الوحدات والبيانات تتبع المشروع المحدد.
- **🔔 مركز الإشعارات الفوري**: جرس أعلى الشاشة يربط دورة المراجعة — المكتب الفني يُشعَر بكل **تقديم جديد** و**إعادة تقديم**، والمقاول يُشعَر **بقرار الاستشاري** (اعتماد/إرجاع مع الملاحظات) و**بالرد على استفساراته وعروضه**، والمالك بعروض الـRFP الموجهة إليه. لكل مستخدم إشعاراته فقط، وفتح الجرس يعلّمها كمقروءة مع بقائها في السجل.
- **📧💬 تسليم الإشعارات على البريد وواتساب**: كل إشعار دورة مراجعة يُسلَّم **فعلياً** إلى المستخدمين المعنيين على بريدهم (Resend/SendGrid) و/أو واتساب (Meta Cloud API) حسب تفضيلات كل مستخدم. لكل مستخدم صفحة **⚙ إعدادات الإشعارات** (من الجرس) يضبط فيها بريده وجواله وقنوات وصوله، والأدمن يرى قنوات كل مستخدم ويضيفها عند الإنشاء. أي قناة غير مهيأة على الخادم تُسجَّل محاولتها كمحاكاة موثّقة في **سجل الإرسال** (الذي يميّز الإشعارات الآلية عن التقارير اليدوية)، وتبقى الإشعارات داخل النظام تعمل دائماً.
- **⏰ تنبيهات التأخر عن المهلة (SLA)**: أي تقديم أو استفسار في المراجعة أكثر من 7 أيام يُعلَّم "متأخر" بعدد أيامه، مع مؤشر إجمالي للمتأخرات في تتبع التقديمات.
- **📥 تصدير CSV**: سجلات التقديمات وRFI/RFP وأوامر التغيير تُصدَّر بضغطة زر بترميز يفتح عربياً في Excel.

## مؤشر صحة المشروع (ذكاء تنفيذي بنظرة)

- **🧭 مؤشر صحة المشروع المركّب (0–100)**: درجة واحدة تُلخّص حالة المشروع للمالك، محسوبة آلياً من خمسة أبعاد بأوزانها — **الجدول الزمني (30%)**، **التكلفة (25%)**، **الجودة (20%، من عدم المطابقة والاختبارات الراسبة وملاحظات التسليم)**، **السلامة (15%، من تقارير السلامة والحوادث المفتوحة)**، و**أداء المقاولين (10%، من التأخر وتجاوز الصرف)** — مع درجة تقييم ملوّنة (A ممتاز / B جيد / C يحتاج متابعة / D حرج) وأشرطة تفصيل لكل بُعد.
- **📅 تقدير آلي لتاريخ الإنجاز**: يُحسب من الوتيرة الفعلية (نسبة الإنجاز ÷ الأيام المنقضية)، ويقارَن بالتاريخ التعاقدي فيعرض التأخّر/التقدّم المتوقع بالأيام.
- تظهر البطاقة في **صفحة "عين المالك"** لكل مشروع وفي **لوحة القيادة**، فتربط كل الوحدات (الإنجاز، التكلفة، الجودة، السلامة، المقاولون) في حكم واحد فوري دون قراءة تقارير.
- **📊 اتجاه المؤشر شهرياً**: رسم بياني لمسار صحة المشروع عبر الأشهر (يُلحق به المؤشر الحالي)، مع مقارنة بالشهر السابق (▲/▼ نقطة) وحكم على الاتجاه العام (صاعد/مستقر/هابط يتطلب خطة تصحيحية) — فيرى المالك الاتجاه لا اللقطة فقط.
- **🚨 تنبيه تلقائي عند هبوط الدرجة**: يُحسب المؤشر في الخادم (مصدر موثوق) ويُسجَّل شهرياً، وعند **هبوط الدرجة لفئة أدنى** (مثلاً B→C) يُطلَق تنبيه تلقائي يصل **للمالك والاستشاري** داخل النظام وبالبريد/واتساب عبر نظام الإشعارات — مرة واحدة لكل هبوط (بلا إزعاج متكرر)، مع تسجيله في سجل النظام.

## المراحل ووحدة التسليم والإغلاق (Handover)

- **🗂️ مراحل المشروع الموسّعة والقابلة للتخصيص**: مكتبة مراحل معيارية (18 مرحلة) تشمل — إضافةً للأساسات والهيكل والمباني والـMEP والتشطيبات والواجهات والفرش والتشغيل — مراحل: التصميم واعتمادات الاستشاري، الطرح واختيار المقاول، التجهيز وتأسيس الموقع، الهيكل المعدني، العزل المائي/الحراري/الصوتي، الأعمال الخارجية والمواقف، التنسيق والتشجير، البنية التحتية والخدمات، اختبار وتشغيل الأنظمة، تسليم المشروع، وفترة ضمان العيوب (DLP). **قوالب مراحل حسب نوع المشروع** (برج تجاري / فيلا / مجمع صناعي) تُطبَّق بضغطة، مع إضافة/تعديل/حذف أي مرحلة لكل مشروع.
- **🏁 وحدة التسليم والإغلاق المتكاملة** بست لوحات:
  - **قائمة تسليم تفاعلية** لكل بند حالة قابلة للتحديث ورفع مستنده داخل المنصة — تشمل المستندات (شهادات التسليم الابتدائي والنهائي، شهادات الاختبار والتشغيل، كتيبات O&M، مخططات As-Built، شهادات الضمان، تقرير الفحص النهائي) والمتطلبات النظامية (شهادة إتمام البناء من الأمانة، الدفاع المدني، موافقة SEC، شهادة الإشغال، سجل المفاتيح).
  - **📌 قائمة الملاحظات (Punch List)** مرتبطة بالمقاول المسؤول مع تتبع فتح/إغلاق لكل ملاحظة، مجمّعة حسب المقاول وقابلة للطباعة، والمقاول يُشعَر بما يُسند إليه ويغلق ملاحظاته.
  - **🛡️ سجل الضمانات** مع **تنبيهات آلية لقرب الانتهاء** (≤90 يوماً) وحساب تواريخ الانتهاء تلقائياً.
  - **🔑 سجل تسليم المفاتيح** بالمناطق والأعداد والتوقيع.
  - **🏁 لوحة فترة ضمان العيوب (DLP)** بحساب المدة المنقضية/المتبقية والعيوب المفتوحة تحت المسؤولية.
  - **📄 تقرير التسليم الموحّد** قابل للتصدير PDF للعميل **بالعربية والإنجليزية** (طباعة/حفظ PDF).
  - **🔍 مراجعة مستندات التسليم داخل المنصة**: أي مستند مرفوع لبند تسليم يُفتح مباشرةً في عارض الـPDF/الترميز للمراجعة دون تنزيل.
- **🏁 جاهزية التسليم بنظرة**: بطاقة موجزة في صفحة "عين المالك" تعرض نسبة اكتمال بنود التسليم، الملاحظات المفتوحة، حالة الموافقات النظامية (أمانة/دفاع مدني/SEC/إشغال)، والضمانات قرب الانتهاء — تربط وحدة التسليم بالرؤية اللحظية للمالك.

## تحسينات المتابعة والتقارير

- **📊 مقارنة الإنجاز الفعلي بالمخطط لكل مقاول** برسم بياني على صفحة المقاولين، مع تعليم المتأخرين آلياً.
- **📥 رفع جداول الكميات (BOQ)** كملفات مُكوَّدة مرتبطة بالمشروع، وربط الكميات بنسب الإنجاز التي تغيّر سطوع المخططات.
- **⚡ توليد تقارير التقدم بضغطة واحدة** (أسبوعي/شهري) جاهزة للإرسال للعميل، **بالعربية أو الإنجليزية**، تجمّع المؤشرات ونسب المراحل وأداء المقاولين تلقائياً.
- **👤 إسناد الجهة المسؤولة لكل تنبيه ذكي** مباشرةً من صفحة الذكاء الاصطناعي — يُشعَر المقاول المسند إليه.
- **📋 تحويل تنبيهات سلامة الكاميرات إلى تقارير حوادث** موثّقة قابلة للأرشفة والطباعة (من صفحتي الذكاء الاصطناعي والكاميرات).
- **💵 مخطط التدفق النقدي** (الوارد من المالك مقابل المنصرف للمقاولين) مربوط بنسب الإنجاز على لوحة القيادة، مع صافي التدفق.

## الصلاحيات وسجل النظام

- **إدارة مستخدمين متكاملة** (أدمن + ممثل المالك): إنشاء حسابات الأدوار الأربعة — المالك (يُسند لمشروعه فيرى صفحته فقط)، ممثل المالك (كل المشاريع)، الاستشاري (كل المشاريع أو مشاريع محددة)، المقاول (مربوط بعقده) — مع مصفوفة صلاحيات موضحة، وتوليد كلمة مرور تُعرض **مرة واحدة** عند الإنشاء ثم تبقى مشفرة للأبد.
- **📜 سجل النظام (Audit Log)**: توثيق كل عملية — دخول، إضافة، تعديل، حذف، قرارات الاعتماد الموقعة، إرسال التقارير، رفع الملفات، لقطات الكاميرات — بفلاتر وبحث، يطلع عليه الأدمن وممثل المالك (آخر 800 حدث).
- تقييد النطاق يُنفَّذ في الخادم (وليس الواجهة): بيانات المشروع تُرشَّح حسب `projectIds` للمستخدم قبل إرسالها.

## قاعدة البيانات والخدمات الحقيقية

| الخدمة | التفعيل | بدون تهيئة |
|---|---|---|
| **قاعدة البيانات SQLite** | تلقائي (WAL، كتابة معاملاتية) | — |
| **رفع الملفات** | تلقائي — `POST /api/upload` وتُقدَّم من `/uploads/` | — |
| **تحليل الصور AI** (Claude Vision) | `ANTHROPIC_API_KEY` + `npm i @anthropic-ai/sdk` | رسالة توضح التهيئة |
| **البريد** | `RESEND_API_KEY` أو `SENDGRID_API_KEY` | يُسجل كمحاكاة |
| **واتساب** (Meta Cloud API) | `WHATSAPP_TOKEN` + `WHATSAPP_PHONE_ID` | يُسجل كمحاكاة |
| **لقطات الكاميرات** | `CAMERA_KEY` ثم تدفع الكاميرا/NVR لقطاتها:<br>`POST /api/cameras/:id/snapshot` بترويسة `x-camera-key` | مغلق |
| **البث المباشر RTSP** | خادم MediaMTX + `MEDIA_SERVER_URL` — البث يظهر حياً داخل بطاقات صفحة الكاميرات | مشهد محاكاة |

انسخ `.env.example` إلى `.env` واملأ ما تحتاجه — كل القيم اختيارية، وصفحة **⚙️ التكامل والإعدادات** داخل النظام تعرض حالة كل خدمة. اللقطات المدفوعة من الكاميرات تُحلَّل تلقائياً بالذكاء الاصطناعي (إن كان مهيأً) وتضاف نتائجها إلى رؤى بصير مع مقارنة نسب الاستشاري.

### الـ API

- `POST /api/login` · `POST /api/logout` · `GET /api/me`
- `GET /api/state` — لقطة كاملة مُرشّحة حسب دور المستخدم
- `GET /api/summary/contractors` — ملخص أداء المقاولين
- `POST/PUT/DELETE /api/collections/:name[/:id]` — CRUD بقواعد صلاحيات
- `POST /api/actions/review` — قرار الاستشاري (اعتماد/رفض بتوقيع)
- `POST /api/actions/add-contractor` · `add-project` · `send-report`

المصادقة بتوكنات JWT موقعة (تبقى بعد إعادة التشغيل) مع حد لمحاولات الدخول، والتخزين في SQLite، ونفس نواة المنطق (`shared/api-core.js`) تشغّل وضع الديمو داخل المتصفح فيتطابق سلوك النسختين.

مسارات إضافية: `POST /api/upload` (رفع فعلي) · `GET /api/integrations/status` · `POST /api/actions/analyze-photo` (تحليل AI) · `POST /api/cameras/:id/snapshot` (مدخل الكاميرات).
