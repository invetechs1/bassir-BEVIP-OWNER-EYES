# 👁 بصير — عيون المالك | Bassir Owner Eyes

منصة رؤية بصرية لإدارة المشاريع الإنشائية تربط **المالك** بـ **المكتب الاستشاري** و**المقاولين**، بحيث يعرف المالك حالة مشروعه **من النظر** — دون حاجة لوقت أو خبرة هندسية.

> الفكرة: المخططات والنموذج ثلاثي الأبعاد تظهر **داكنة** للأعمال غير المنتهية وتتحول إلى **ساطعة متوهجة** كلما اكتملت البنود واعتُمدت مستخلصاتها.

---

## التشغيل

بدون أي اعتماديات خارجية — يلزم Node.js 16+ فقط:

```bash
node server/server.js
# ثم افتح http://localhost:3000
```

- `npm run seed` — إعادة ضبط بيانات الديمو
- `npm run build:demo` — توليد ديمو تفاعلي بملف واحد `demo/bassir-demo.html` يعمل بلا خادم (يفتح مباشرة في المتصفح)

## المستويات والصفحات

### 1) الأدمن
مطلع على كل شيء: جميع الصفحات + إدارة المستخدمين (مع كلمات المرور) + حذف السجلات.

### 2) المالك
- **لوحة القيادة**: الجدول الزمني الفعلي والتقديري (منحنى S)، التكلفة الفعلية والتقديرية، مراحل المشروع، تنبيهات ذكية.
- **رؤية المشروع**:
  - مخططات 2D لكل دور مربوطة بجدول الكميات — المناطق داكنة للبنود غير المنتهية وساطعة للمنتهية، مع تصفية حسب التخصص (معماري، إنشائي، كهرباء، HVAC، صحي، حريق، فرش...).
  - نموذج BIM أيزومتري مربوط بجدول الكميات — الأدوار المكتملة تتوهج، والضغط على أي دور يعرض تفصيل تخصصاته.
- **المقاولون والأداء**: عدد المقاولين، نسبة إنجاز كل مقاول، المبالغ المستلمة، التخصص، هل هو متأخر؟ هل استلم أكثر من مستحقه؟ (مقارنة بالقيمة المكتسبة Earned Value).
- **ذكاء بصير الاصطناعي**: نسبة إنجاز مرصودة بصرياً من الصور والكاميرات مقابل المُبلَّغ، رؤى ونصائح وتنبيهات (فروقات إنجاز، تأخر وتيرة، تنبيهات سلامة ومالية).
- **التقارير والإرسال**: تقارير يومية وشهرية + إرسال للمالك عبر واتساب أو الإيميل مع سجل إرسال.

### 3) ممثل المالك
كل ما يراه المالك + **إضافة مشروع وتعيين استشاري** وإنشاء اسم مستخدم وكلمة مرور له + إدارة المستخدمين.

### 4) الاستشاري (المكتب الفني)
- **الاعتمادات**: استقبال طلبات المقاولين والبت فيها بتوقيع إلكتروني وملاحظات — المخططات التنفيذية، الجداول الزمنية، المواد والداتا شيت، طلبات استلام الأعمال (قبول / قبول بملاحظات / رفض)، أوامر التغيير، **المستخلصات** (اعتمادها يحدّث نسب بنود الكميات فتتحول المخططات من داكنة إلى ساطعة ويُحدَّث رصيد المقاول).
- **جداول الكميات**: عرض وتحديث نسب الإنجاز لكل بند (ينعكس مباشرة على المخططات).
- **إدارة المقاولين**: إضافة مقاول بجدول كمياته وأسعاره وتواريخ عقده وتخصصه + إنشاء حساب دخول له.
- **رفع نموذج BIM** وربطه بجدول الكميات.
- **التقارير اليومية** بالصور والملفات الداعمة، والتقارير الشهرية.

### 5) المقاول
- الاطلاع على عقده: القيمة، تاريخا البدء والانتهاء، نسبة إنجازه، المبالغ المستلمة.
- رفع طلباته للاستشاري ومتابعة حالتها: مخططات، مواد، جداول زمنية، طلبات استلام، أوامر تغيير، مستخلصات (مع ربط بنود الكميات ونِسَبها).

## البنية

```
├── server/server.js       خادم HTTP + API (بدون اعتماديات)
├── shared/
│   ├── seed-data.js       بيانات الديمو (تعمل في Node والمتصفح)
│   └── api-core.js        نواة المنطق والصلاحيات المشتركة
├── public/                الواجهة (SPA عربية RTL)
│   ├── index.html
│   ├── css/styles.css
│   └── js/  api.js · charts.js · views.js · views2.js · app.js
├── tools/build-demo.js    مولّد الديمو أحادي الملف
└── data/db.json           قاعدة البيانات (تُنشأ تلقائياً)
```

### الـ API

- `POST /api/login` · `POST /api/logout` · `GET /api/me`
- `GET /api/state` — لقطة كاملة مُرشّحة حسب دور المستخدم
- `GET /api/summary/contractors` — ملخص أداء المقاولين
- `POST/PUT/DELETE /api/collections/:name[/:id]` — CRUD بقواعد صلاحيات
- `POST /api/actions/review` — قرار الاستشاري (اعتماد/رفض بتوقيع)
- `POST /api/actions/add-contractor` · `add-project` · `send-report`

المصادقة عبر Bearer token، والتخزين في `data/db.json`، ونفس نواة المنطق (`shared/api-core.js`) تشغّل وضع الديمو داخل المتصفح فيتطابق سلوك النسختين.
